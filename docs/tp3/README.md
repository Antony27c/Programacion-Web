# TP3 — Wireframe y mockups UI/UX (Figma)

Diseño de la interfaz del sitio del taller **BOXLY** (servicio mecánico
automotor, Salta): primero el wireframe de baja fidelidad y después los mockups
de alta fidelidad en Figma, listos para maquetar en el TP4.

## Objetivo

- Definir la propuesta del sitio: tema, justificación y sitios de referencia.
- Elaborar el **wireframe** del sitio (estructura y distribución de contenido).
- Diseñar los **mockups UI/UX** de todas las vistas y componentes en Figma,
  con paleta y tipografías definidas.

## Informe del TP

El documento [`Programación-Web-TP3.docx`](Programación-Web-TP3.docx) contiene la
fundamentación de la entrega:

- **Tema elegido:** sitio web para un taller de servicio mecánico automotor.
  Se eligió por la formación técnica del alumno como Técnico en Automotores
  (ETT N°3139): permite entender el rubro y pensar la UX para un usuario que
  busca rapidez y confianza.
- **Sitios de referencia:** Mecánica Alvaro, MDO Garage, Taller Repro,
  Meineke Car Care y Feu Vert.
- **Repositorio:** https://github.com/Antony27c/Programacion-Web

## Mockups UI/UX

Los mockups exportados como PNG están en [`mockups/`](mockups/), con un
[`README`](mockups/README.md) que enlaza cada imagen. Incluyen:

- **12 pantallas + portada:** Home, Nosotros, Servicios, Servicio Detalle,
  Agendar Turno, Presupuesto, Testimonios, Galería, Contacto, Promociones,
  FAQ y Equipo.
- **Componentes:** Header y Footer de navegación (`mockups/Nav/`), botones
  `Primary` y `Ghost` (`mockups/Button/`).

**Enlace al archivo de Figma:**
https://www.figma.com/design/1MKE3Skw1MhIkSsq2L2091/Taller-Mecanico-Mockups-UI-UX-TP3

## Sistema visual definido

| Elemento | Decisión |
|----------|----------|
| Tipografías | Oswald (títulos) + Work Sans (cuerpo) |
| Estructura / header-footer | `#0F172A` (Ink) |
| Texto principal | `#1E293B` |
| Acento / CTA / marca | `#0052FF` |
| Texto secundario | `#6C757D` (Titanio) |
| Fondos | `#F8F9FA` · cards `#FFFFFF` |
| Éxito | `#10B981` |
